# Patrick Lowry

I work at the UK AI Security Institute and I'm interested in AI safety.

In my own time I build software to solve problems I run into. The projects below are personal and unrelated to my work at the Institute.

## Projects

- **Crumbs:** a mobile app for planning a surprise date as a trail of location clues. Each clue unlocks only when the player reaches the previous stop. Steps are encrypted so later clues can't be read early, and the trail works offline with no server. TypeScript, Expo and React Native.
  
- **Dictaphone:** a macOS menu-bar app for private dictation and meeting notes. It transcribes speech on the device with Whisper, separates speakers in meetings and reads text aloud. Swift.
  
- **CharterME:** helps engineers prepare Chartered Engineer applications by tracking competencies, organising evidence and drafting the final submission with an LLM. React, TypeScript and the Gemini API.
  
- **Lowry Secret Santa:** a web app that runs my family's Secret Santa. It draws names so that nobody knows the full result, and each person sees only their own match and that person's wish list. JavaScript, Supabase and Vercel.
  
- **My Cook Book:** a recipe and shopping app for my household. It imports a recipe from any link by reading its structured data, matches each ingredient to a Sainsbury's product to price the meal, and builds a shared shopping list. Next.js, TypeScript, Supabase and Vercel.
